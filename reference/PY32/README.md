# PY32 reference material

The original engineering package included unit-firmware and protocol material
for interoperability and hardware-reference purposes. Those files are separate
from the ESP32-S3 controller source under `firmware/Master_C3/`.

They are intentionally not redistributed in this public repository because
their third-party redistribution terms have not been established. Obtain the
appropriate PY32 firmware and protocol documentation through the authorized
hardware/vendor channel. Do not flash ESP32-S3 images to a PY32 unit, or PY32
images to the ESP32-S3 controller.
